# バドミントン対戦表

iPhoneのブラウザで使える、練習会向けダブルス対戦表です。公開先はGitHubとRenderの静的サイトです。

## オフライン版

「臨時練習」は参加者・コート・対戦履歴を端末のブラウザに保存します。公開ページを一度開いてアプリ本体を読み込めば、ネット接続がない場所でも利用できます。Safariの共有メニューから「ホーム画面に追加」すると起動しやすくなります。

## オンライン版

1. オンラインを選び、名前を入れて「部屋を作る」を押します。
2. 表示された6桁コードを参加者に伝えます。
3. 参加者はそれぞれ名前とコードを入力して「部屋に入る」を押します。入室と同時に名前が名簿へ加わります。
4. 名簿、コート数、対戦表、選手の入れ替えがリアルタイム共有されます。

対戦会のホスト端末が部屋の一時データを持ち、参加者のブラウザ間でPeerJS/WebRTC通信します。部屋データは保存されません。ホストが退出またはブラウザを閉じると部屋が終了します。参加者はホストの画面を開いたままにしてください。PeerJS Cloudは接続の仲介に使い、データは基本的に端末間で直接送受信されます。PeerJS Cloudの障害やネットワーク設定によって接続できない場合があります。

## 公開

GitHubのmainブランチへの変更はRenderの静的サイトへ自動反映されます。Renderにオンライン用サーバーやデータベースを追加する必要はありません。
