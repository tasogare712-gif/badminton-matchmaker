# バドミントン対戦表

iPhoneのブラウザで使える、練習会向けダブルス対戦表アプリです。インストール後は臨時練習用モードをオフラインでも利用できます。

## 使い方

- 「臨時練習」は、参加者・対戦表を端末のブラウザに保存します。ネット接続がなくても利用できます（初回アクセス後にアプリファイルがキャッシュされます）。
- 「固定メンバー」は、Supabaseの共有名簿を全員で使います。URLを知っている人は名簿を追加・削除できます。対戦表は各端末内に保存されます。
- コートを1〜4面から選び、参加者4人以上で対戦表を作成します。
- 対戦表で選手名を2人タップすると入れ替わります。休憩者とコート上の選手も交換できます。
- iPhoneではSafariの共有メニューから「ホーム画面に追加」を選ぶと、アプリとして起動できます。

## 共有版の設定（初回のみ）

1. Supabaseで無料プロジェクトを作成します。
2. Supabase SQL Editorで `supabase-setup.sql` の内容を実行します。
3. SupabaseのProject URLとPublishable key（旧anon key）を `supabase-config.js` に設定し、GitHubへ反映します。Publishable keyはブラウザ用の公開キーです。Secret / service_role keyは絶対に使わないでください。
4. Renderの自動デプロイ完了後、アプリの「固定メンバー」を選びます。最初に登録した名簿が全員に表示されます。

共有版はURLを知る人全員が名簿を読み取り・追加・削除できます。個人情報や電話番号などは登録しないでください。Supabase無料プロジェクトは利用が少ない期間が続くと一時停止することがあります。

## オフライン動作

公開URLを一度開くと、アプリ本体が端末にキャッシュされます。ネットがない場所では「臨時練習」を選んでください。共有名簿の同期にはインターネットが必要です。
