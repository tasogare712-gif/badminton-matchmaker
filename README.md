# バドミントン対戦表

iPhoneのブラウザで使える、練習会向けダブルス対戦表です。

## オフライン版

「臨時練習」は今までどおり、参加者・コート・対戦履歴を端末のブラウザに保存します。公開ページを一度開いてアプリ本体を読み込めば、ネット接続がない場所でも利用できます。Safariの共有メニューから「ホーム画面に追加」すると起動しやすくなります。

## オンライン版

1. オンラインを選び、自分の名前を入れて「部屋を作る」を押します。
2. 表示された6桁コードを参加者に伝えます。
3. 他の参加者はそれぞれ名前とコードを入力して「部屋に入る」を押します。入室時に名簿へ追加されます。
4. 参加者名簿とコート・対戦表は部屋内でリアルタイム共有されます。名前をタップして選手を入れ替える操作も全員に反映されます。

部屋と名簿は練習用の一時データで、作成から3時間後に自動削除されます。Cloudflare Workers Freeの利用上限を超えた場合は接続・更新がエラーになり、従量課金には移行しません。WorkersプランはFreeのまま利用し、Workers Paidへアップグレードしないでください。

## Cloudflare Workersの設定

- `wrangler.toml` と `worker.js` はオンライン部屋サーバーの設定です。`ROOMS` Durable ObjectはSQLite-backed Free bindingで動きます。
- GitHubに接続してCloudflare Workersへデプロイします。WorkerのURLが決まったら `room-config.js` の `ROOM_SERVER_ORIGIN` をそのURLに設定します。
- オンライン部屋は当面、`https://badminton-match-table.onrender.com` からアクセスできるようにCORSを設定しています。公開URLを変更した場合はWorkerの `ROOM_ORIGINS` も合わせて変更してください。

このプロジェクトは利用名簿を長期保管しません。参加者名には個人情報を入力しないでください。
