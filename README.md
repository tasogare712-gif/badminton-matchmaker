# バドミントン対戦表

iPhoneのブラウザで使える、練習会向けダブルス対戦表アプリです。

## 起動方法

1. Visual Studio Codeでこの `badminton-matchmaker` フォルダを開きます。
2. `index.html` をブラウザで開きます（VS Code拡張 Live Server を使うと便利です）。

ビルドやパッケージのインストールは不要です。Webサーバーに配置すればiPhoneからアクセスできます。

## 使い方

- コートを1〜4面から選びます。
- 名前を入力して参加者を追加し、不要な人は「×」で削除します。
- 参加者が4人以上になったら「対戦表を作成」を押します。
- 「次の対戦を作成」でラウンドを進めます。コートに入らない参加者は休みになります。
- 参加者・コート数・ラウンドはブラウザのローカルストレージに保存されます。

対戦は、登録済みの履歴を参照して同じペアや対戦相手の重複を抑える簡易方式で組みます。練習会データは同じ端末・同じブラウザ内に保存されます。
