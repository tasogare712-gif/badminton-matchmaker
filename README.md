# バドミントン対戦表

iPhoneのブラウザで使える、練習会向けダブルス対戦表アプリです。

## 使い方

- 「臨時練習」は、参加者・対戦表を端末のブラウザに保存します。公開URLを一度開いた後は、オフラインでも利用できます。
- 「オンライン」は名前を入力して部屋を作成し、発行された6桁の部屋コードを共有します。参加者は名前と部屋コードを入力して入室します。入室した名前は部屋の参加者に自動追加され、名簿と対戦表がリアルタイムで共有されます。
- コートを1〜4面から選び、4人以上で対戦表を作成します。
- 対戦表で選手名を2人タップすると入れ替わります。休憩者とコート上の選手も交換できます。
- iPhoneではSafariの共有メニューから「ホーム画面に追加」を選ぶと、アプリとして起動できます。

## オンライン部屋の動作

オンライン部屋はRenderの無料WebSocketサーバー上の一時データです。部屋に接続中の参加者が操作する間、名簿と対戦表を共有します。Render無料サービスは15分間通信がないと停止し、再起動に約1分かかる場合があります。サーバー再起動やデプロイが起きると部屋と参加者名簿は消えるため、練習会ごとに新しい部屋を作成してください。保存が必要な個人情報は登録しないでください。

## Render構成

`render.yaml` は、GitHubリポジトリにオンライン部屋用の無料Web Serviceを追加する設定です。現在の静的サイトはそのまま臨時練習用として残ります。新しいWeb ServiceのURLを取得した後、`room-config.js` のWebSocket URLが実際のRender URLと一致していることを確認してください。
